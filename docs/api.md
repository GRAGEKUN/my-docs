# API 参考

以下接口仅用于文档展示，**不提供真实服务**，目的是练习接口描述的写法。

## 查询文档列表

- 请求方法：`GET`
- 请求路径：`/api/docs`
- 功能：返回文档条目列表。
- 查询参数：`page`（可选，默认 1）

### 请求示例

```bash
curl -s "https://example.com/api/docs?page=1"
```

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

## 查询单篇文档

- 请求方法：`GET`
- 请求路径：`/api/docs/{id}`
- 功能：按 id 返回单篇文档的标题与正文。

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "body": "..."
}
```

## 接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/docs` | 文档列表，支持分页 |
| GET | `/api/docs/{id}` | 单篇文档详情 |
| GET | `/api/health` | 健康检查，返回 `ok` |

## 状态码约定

| 状态码 | 含义 |
| --- | --- |
| 200 | 请求成功 |
| 404 | 文档不存在 |
| 500 | 服务端错误 |
